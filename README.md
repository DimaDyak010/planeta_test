# Материалы «Моя Планета»

Приложение на Nuxt для просмотра и создания материалов.

## Требования

- Node.js 22 или новее
- npm

## Установка и запуск

Установите зависимости:

```bash
npm install
```

Скопируйте пример переменных окружения и укажите секретный alias внешнего API в `.env`:

```bash
cp .env.example .env
```

Переменная `NUXT_MATERIALS_ALIAS` используется только сервером. Не добавляйте `.env` в Git и не публикуйте его содержимое.

Запустите приложение в режиме разработки:

```bash
npm run dev
```

Откройте адрес, указанный в терминале (по умолчанию `http://localhost:3000`).

Для локального запуска production-версии:

```bash
npm run build
npm run preview
```

## Получение данных материала

Для детальной страницы выбран серверный endpoint `GET /api/materials/:id`. Он получает список материалов от внешнего API, находит нужный материал по ID на сервере и возвращает клиенту только его.

После создания материала используется материал из ответа `POST`, поэтому для него не выполняется дополнительный запрос.

## Проверка длины полей

Максимальная длина `title` — 80 символов, `short_description` — 255 символов. Форма ограничивает ввод через `maxlength`. Сервер повторно проверяет тип, заполненность и длину обоих полей перед отправкой данных во внешний API. При нарушении ограничений сервер возвращает `400`.

## CORS

Браузер отправляет запросы на same-origin Nuxt API (`/api/materials`). Запрос к внешнему API выполняет Nuxt-сервер, поэтому браузерный CORS-запрос к стороннему домену не возникает и отдельная CORS-настройка не потребовалась.
